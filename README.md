# Dating Coach Skill

一个以证据为先的中文线上约会聊天教练 Skill。它帮助用户看懂聊天记录、估计互动中实际呈现的关系阶段、复盘反复出现的沟通模式，并练习写出符合自己语气的回复。

它不是“万能话术库”，也不承诺靠某句话制造吸引。核心目标是提高观察、判断、表达和边界意识。

## 能做什么

- 区分已确认事实、较可能解释、竞争性解释和未知信息。
- 从连续性、双向投入、个人深度、暧昧表达、实际行动和边界安全判断关系阶段。
- 识别聊天中的关键转折点与反复互动循环。
- 评价用户自己的回复，并用一次只改一个变量的方式练习。
- 在用户明确需要措辞时，根据当前聊天原创建议，不调用固定话术库。

## 设计原则

- 明确表达与实际行动，权重高于回复速度、表情、点赞等弱信号。
- 阶段标签描述的是聊天中呈现出的互动，不等于读懂对方内心。
- 消息质量和结果分开评价；合理的消息也无法创造不存在的双向兴趣。
- 关系推进必须匹配已经表现出的舒适度与双向投入。
- 尊重成年人之间的知情同意、拒绝、隐私和退出权。

## 使用

将仓库目录放入 Codex 用户级技能目录：

```text
~/.codex/skills/dating-coach/
```

或者放入项目级技能目录：

```text
<project>/.agents/skills/dating-coach/
```

示例请求：

```text
$dating-coach 帮我分析这段聊天。先区分事实和推测，再判断当前阶段。
$dating-coach 复盘一下这段对话，找出我的沟通习惯和下次实验。
$dating-coach 给我一道“自然推进邀约”的练习题，我先作答。
```

## 原创性与来源

这是由本仓库维护者完成的原创综合设计与实现，并非任何上游项目的复制或官方衍生版本。它研究了若干公开关系沟通 Skills 的架构，但重新设计了证据层、阶段层和学习层，没有收录或复制其现成话术。

具体参考项目、吸收内容、拒绝的假设及理由见 [`references/source-synthesis.md`](references/source-synthesis.md)。

## 边界

本 Skill 不提供胁迫、骚扰、羞辱打压、伪造身份、操纵嫉妒、利用脆弱状态或无视明确拒绝的方案。它也不构成心理咨询，无法从聊天记录证明一个人的真实动机或人格。
